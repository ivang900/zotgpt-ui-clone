# ZotGPT UI Clone

This project is a static React frontend recreation of the ZotGPT Chat UI. It allows for experimenting with UI changes and design proposals while maintaining parity with the original interface.

## Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```

2. **Navigate into the project directory:**
   ```bash
   cd zotgpt-ui-clone
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **View the app:**
   Open your browser and go to `http://localhost:5173` to see the application running.
